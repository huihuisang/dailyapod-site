# dailyapod.ajigu.com

Product site for [DailyApod — Astronomy Picture](https://apps.apple.com/app/id1573247808), deployed on GitHub Pages with a custom domain (CNAME). Static HTML, no build step.

Languages: `/` (English), `/zh-hans/`, `/ja/`. Edit HTML, commit to `main` to publish. Keep all locales in sync.
